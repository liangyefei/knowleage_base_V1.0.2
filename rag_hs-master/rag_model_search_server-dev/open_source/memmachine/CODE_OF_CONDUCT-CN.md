# 行为准则

## 我们的承诺

作为成员、贡献者和领导者，我们承诺使参与我们的社区成为对每个人都免受骚扰且受到欢迎的体验，无论其年龄、体型、残疾状况、民族、性别认同与表达、经验水平、国籍、个人外貌、种族、宗教或性身份与性取向如何。

## 我们的标准

有助于为我们的社区营造积极环境的行为示例包括：

- 对他人表现出同理心和善意。
- 尊重不同的意见、观点和经验。
- 给予并得体地接受建设性反馈。
- 为我们的错误承担责任并向受影响者道歉，并从中吸取经验。
- 不仅关注对我们个人而言最有利的事物，也关注对整个社区最有利的事物。

## 不可接受的行为

不可接受的行为示例包括：

- 使用性暗示的语言或图像，以及任何形式的令人不适的性关注或性挑逗。
- 恶意挑衅、侮辱性或贬损性评论，以及人身或政治攻击。
- 公开或私下骚扰。
- 未经他人明确许可，发布其私人信息，如物理地址或电子邮件地址。
- 其他在专业场合中可被合理认为不当的行为。

## 举报指南

如遇到辱骂、骚扰或其他不可接受的行为，可通过 GitHub 上的私密渠道联系项目团队进行举报。为此，请通过我们仓库的 [Security 标签页](https://github.com/MemMachine/MemMachine/security) 提交报告。所有投诉都将得到及时、公正的审查和调查。

我们使用 GitHub 的私密漏洞报告功能来处理安全问题。如果您认为自己发现了 MemMachine 中的安全漏洞，**请勿创建公开的 GitHub issue**。相反，请通过我们仓库的 [Security 标签页](https://github.com/MemMachine/MemMachine/security) 进行举报，并点击 "Report a privately reported vulnerability"。

所有项目负责人都有义务尊重任何事件举报者的隐私和安全。

## 执行

项目负责人将遵循 Contributor Covenant 的执行指南来处理每一起事件。不遵守行为准则的项目负责人将面临与社区任何其他成员相同的后果。

## 归属

本行为准则改编自 Contributor Covenant 2.1 版本，可在 [https://www.contributor-covenant.org/version/2/1/code_of_conduct.html](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html) 查阅。
