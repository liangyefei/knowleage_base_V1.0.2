# 配置文件说明

本目录包含项目所有环境的配置文件，采用 YAML 格式。每个环境子目录下维护一套完整配置，根目录为默认配置入口，供本地开发直接加载。

## 环境目录

| 目录 | 部署形态 | 说明 |
|------|---------|------|
| `test/` | 本地 | 本地测试环境，开发者本机调试使用 |
| `devp/` | k8s | k8s 上的 dev 测试环境，用于联调与集成验证 |
| `release/` | k8s | k8s 上的预发布pre-release环境，发布前回归验证 |
| `prod/` | k8s | k8s 上的正式生产环境 |
| 根目录 | 本地 | 默认配置，作为 `configs/` 下加载器的默认入口 |

各子目录内配置文件同名同构，仅取值随环境差异。切换环境时复制对应子目录的文件覆盖根目录，或通过部署脚本指向对应子目录。

## 配置文件清单

每个环境目录下均包含以下 5 个文件，分属不同配置模块（文件内部含详细注释，不再在此展开）：

| 文件 | 作用 |
|------|------|
| `model_config.yaml` | 模型配置（Embedding、LLM、Reranker） |
| `kb_config.yaml` | 知识库配置（向量库、检索参数、存储路径） |
| `basic_config.yaml` | 基础配置（日志、认证） |
| `server_config.yaml` | 服务器配置（API、Redis、服务地址） |
| `prompt_templates.yaml` | 提示词模板 |
