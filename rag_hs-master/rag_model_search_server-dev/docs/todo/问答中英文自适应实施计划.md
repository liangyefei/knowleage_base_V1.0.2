**Goal:** 实现问答中英文自适应——用户英文提问时模型用英文组织答案，中文提问时仍用中文回答，且对现有中文问答流程零回归。

## 与方案的偏差/修正

**`resolve_prompt_name` 命中判定：`isinstance(dict)` → `in` 存在性检查。**

方案 §2.3 原文用 `isinstance(cat.get(en_name), dict)` 判定是否命中英文模板。这只对 `knowledge_base_chat`（system+body 两段式 dict）有效；但 `llm_chat` 与 `search_engine_chat` 的模板是**单字符串**（非 dict），`isinstance(..., dict)` 恒为 False → 英文请求会静默降级回中文模板，`/chat` 英文自适应失效。

本计划改为 `en_name in cat`（存在性检查），同时兼容 dict 与 str 两类模板。这是对方案 §2.3 的必要修正，§2.4.2/§2.4.3 补的单字符串英文模板才能被正确切换。单测（Task 2/4/5）覆盖两类形态。

```python
"""语言检测：基于 langdetect，带 LRU 缓存、CJK 快速通道与代码主导识别。"""
import os
import re
from functools import lru_cache
from typing import Literal

from configs.logger_manager import logger


def _auto_switch_enabled() -> bool:
    """kill-switch：HAISI_LANG_AUTO_SWITCH 默认启用；设为 "0"/"false" 时关闭，
    resolve_language 短路返回 zh（=今天行为，零变更、无需重启）。"""
    return os.environ.get("HAISI_LANG_AUTO_SWITCH", "1") not in ("0", "false", "False", "")


# langdetect 默认带随机性，固定 seed 保证可复现
try:
    from langdetect import detect_langs, DetectorFactory
    DetectorFactory.seed = 0
    _HAS_LANGDETECT = True
except ImportError:  # 依赖缺失时 fail-open，按中文处理
    _HAS_LANGDETECT = False

Lang = Literal["zh", "en"]

# ASCII 字母占比阈值：英文短句（如 "hi"）langdetect 不稳，用字符统计兜底
_EN_ASCII_RATIO = 0.6
_MIN_LEN_FOR_DETECT = 3  # 短于此长度走字符统计快速通道

# 代码符号集（散文中罕见、代码中密集）：用于识别"纯代码/代码主导"输入
_CODE_SYMBOLS = set("{}()[];=<>+-*/\\|&!@#$%^~:`")
# 代码符号占 (符号+字母) 比例阈值：≥ 此值判定为代码主导
_CODE_SYMBOL_RATIO = 0.15
# 代码关键词 + 紧邻代码标点：要求关键词像代码那样被使用（def foo( / return x;）
# 单独出现在散文里的 "return"/"class" 不算（避免 "How to use return" 误判）
_CODE_KW_WITH_PUNCT = re.compile(
    r'\b(?:def|class|import|from|return|public|private|protected|void|'
    r'int|float|double|char|bool|var|let|const|async|await|new|try|catch|'
    r'finally|throw|lambda|fn|func|struct|enum|interface|extends|implements|'
    r'package|namespace|using|#include)\b[^a-zA-Z]{0,3}[(:;{=]'
)
# markdown 代码块 / 行内代码，检测前剥离，用剩余自然语言片段判定语言
_FENCED_CODE = re.compile(r"```[a-zA-Z]*\n?.*?\n```", re.DOTALL)
_INLINE_CODE = re.compile(r"`[^`\n]+`")


def _strip_code_blocks(q: str) -> str:
    """剥离 markdown 代码块（```...```）与行内代码（`...`），返回自然语言片段。"""
    q = _FENCED_CODE.sub(" ", q)
    q = _INLINE_CODE.sub(" ", q)
    return q.strip()


def _is_code_dominant(q: str) -> bool:
    """判断输入是否为代码主导（缺少可识别的自然语言信号）。

    判据（满足任一）：
      1. 代码符号密度 ≥ _CODE_SYMBOL_RATIO
      2. 代码关键词以代码方式使用（紧邻 ( : ; { = 等标点）
    """
    if not q:
        return False
    code_syms = sum(1 for c in q if c in _CODE_SYMBOLS)
    letters = sum(1 for c in q if c.isalpha())
    total = code_syms + letters
    if total > 0 and code_syms / total >= _CODE_SYMBOL_RATIO:
        return True
    if _CODE_KW_WITH_PUNCT.search(q):
        return True
    return False


def _is_cjk_dominant(q: str) -> bool:
    """CJK 字符数 ≥ ASCII 字母数 → 判为中文主导，直接返回 zh 绕过 langdetect。"""
    cjk = sum(1 for c in q if "\u4e00" <= c <= "\u9fff")
    ascii_letters = sum(1 for c in q if c.isalpha() and ord(c) < 128)
    return cjk > 0 and cjk >= ascii_letters


def _by_ascii_ratio(q: str) -> Lang:
    """按 ASCII 字母占比判定：≥_EN_ASCII_RATIO 判英文，否则中文。"""
    letters = [c for c in q if c.isalpha()]
    if not letters:
        return "zh"
    ascii_letters = [c for c in letters if ord(c) < 128]
    return "en" if len(ascii_letters) / len(letters) >= _EN_ASCII_RATIO else "zh"


def detect_language(query: str) -> Lang:
    """检测 query 主语言，返回 'zh' 或 'en'。

    优先级：
    1. 空/纯标点 → 'zh'
    2. 剥离代码块后自然语言为空 → 纯代码 → 'zh'
    3. CJK 占优 → 'zh'，绕过 langdetect（不阻塞 async 事件循环）
    4. 代码主导 → 'zh'
    5. 极短文本 → ASCII 占比判定
    6. langdetect 检测
    7. langdetect 异常/非中英 → 字符占比兜底
    8. 全部失败 → 'zh'
    """
    if not query or not query.strip():
        return "zh"
    q = query.strip()

    prose = _strip_code_blocks(q)
    if not prose:
        return "zh"

    if _is_cjk_dominant(prose):
        return "zh"

    if _is_code_dominant(prose):
        logger.debug(f"[lang] code-dominant input, keep default zh | query={q[:40]}")
        return "zh"

    if len(prose) <= _MIN_LEN_FOR_DETECT or not _HAS_LANGDETECT:
        return _by_ascii_ratio(prose)

    try:
        langs = detect_langs(prose)
        if langs:
            top = langs[0].lang  # 如 'en', 'zh-cn', 'zh-tw'
            if top.startswith("en"):
                return "en"
            if top.startswith("zh"):
                return "zh"
        return _by_ascii_ratio(prose)
    except Exception as e:
        logger.debug(f"[lang] detect 失败 fail-open=zh: {e} | query={q[:40]}")
        return _by_ascii_ratio(prose)


@lru_cache(maxsize=2048)
def detect_language_cached(query: str) -> Lang:
    """带 LRU 缓存的检测：同一 query 二次请求 O(1) 命中。"""
    return detect_language(query)


def resolve_language(query: str, explicit: str = "auto") -> Lang:
    """融合显式参数与自动检测：explicit != 'auto' 时直接采用，否则检测。

    kill-switch 优先：HAISI_LANG_AUTO_SWITCH=0 时直接返回 zh，忽略显式覆盖。
    """
    if not _auto_switch_enabled():
        return "zh"
    if explicit == "en":
        return "en"
    if explicit == "zh":
        return "zh"
    return detect_language_cached(query)
```

```python
def resolve_prompt_name(category: str, prompt_name: str, language: str) -> str:
    """根据语言解析最终模板名：language=='en' 时优先取 'en_{prompt_name}'，
    不存在则降级回 prompt_name（优雅降级，不报错）。

    用于 multi_knowledge_base_chat / file_chat / chat 等端点的模板选择层，
    把"语言 → 模板名"映射收敛到一处，避免各端点各自 if-else。

    兼容两类模板形态：
      - system+body 两段式 dict（knowledge_base_chat.*）
      - 单字符串（llm_chat.* / search_engine_chat.*）
    命中判定用存在性检查（en_name in cat），而非 isinstance(dict)，
    否则单字符串英文模板会被误判为"未命中"而降级回中文。

    Args:
        category: 模板类别（如 "knowledge_base_chat"）
        prompt_name: 请求传入的基础模板名（如 "default"/"text"/"think"/"empty"）
        language: "zh" 或 "en"

    Returns:
        最终模板名。en 命中则 "en_{prompt_name}"，否则 prompt_name。
    """
    if language != "en":
        return prompt_name
    from configs import prompt_loader
    templates = prompt_loader.get_loader().load()
    cat = templates.get(category, {})
    en_name = f"en_{prompt_name}"  # chitchat → en_chitchat，命名统一，无需特判
    if en_name in cat:
        return en_name
    return prompt_name  # 降级回中文模板
```

```
def _build_route_summary(ctx: ChatContext) -> str:
    """根据路由阶段写入的 kb_stats/ctx，生成完成时态的"分析完成"结论文案。

    用于 _phase_generate 开头补发的 route_reasoning 收尾事件，让前端时间线
    从"正在..."收尾为带结论的完成态，避免回答结束后仍残留进行时提示。

    """

    keywords = ctx.route_keywords or []
```

```python
def _sse_post(url: str, payload: dict, timeout: float = 90.0) -> list[dict]:
    """发 POST，解析 SSE `data:` 行，返回事件 dict 列表。"""
    events = []
    with httpx.Client(timeout=timeout) as c:
        with c.stream("POST", url, json=payload) as r:
            r.raise_for_status()
            for line in r.iter_lines():
                if not line or not line.startswith("data:"):
                    continue
                try:
                    events.append(json.loads(line[5:].strip()))
                except Exception:
                    pass
    return events


def _answer(events: list[dict]) -> str:
    return "".join(e.get("answer", "") for e in events if "answer" in e)


def _final_docs(events: list[dict]) -> tuple[list, dict]:
    for e in reversed(events):
        if "docs" in e:
            return e["docs"], e.get("kb_stats", {})
    return [], {}


def _cjk_ratio(text: str) -> float:
    if not text:
        return 0.0
    cjk = sum(1 for c in text if "\u4e00" <= c <= "\u9fff")
    letters = sum(1 for c in text if c.isalpha())
    return cjk / letters if letters else 0.0


def _is_english(text: str) -> bool:
    return _cjk_ratio(text) < 0.2


def _is_chinese(text: str) -> bool:
    return _cjk_ratio(text) >= 0.2

            "user_id": _USER,
            "stream": stream,
            "language": language,
            "top_k": 3,
        }
    return _make

        events = _sse_post(kb_chat_url, kb_payload("Hi3798MV310 的启动流程是什么？"))
        ans = _answer(events)
        assert ans, "答案为空"
        assert _is_chinese(ans), f"中文提问应中文回答，CJK 占比过低: {_cjk_ratio(ans):.2f}"

    def test_english_query_english_answer(self, kb_chat_url, kb_payload):
        events = _sse_post(kb_chat_url, kb_payload("What is the boot process of Hi3798MV310?"))
        ans = _answer(events)
        assert ans, "答案为空"
        assert _is_english(ans), f"英文提问应英文回答，CJK 占比过高: {_cjk_ratio(ans):.2f}"

    def test_explicit_en_on_chinese_query(self, kb_chat_url, kb_payload):
        events = _sse_post(kb_chat_url, kb_payload("Hi3798MV310 的启动流程是什么？", language="en"))
        ans = _answer(events)
        assert _is_english(ans), "显式 en 覆盖应英文回答"

    def test_explicit_zh_on_english_query(self, kb_chat_url, kb_payload):
        events = _sse_post(kb_chat_url, kb_payload("What is the boot process of Hi3798MV310?", language="zh"))
        ans = _answer(events)
        assert _is_chinese(ans), "显式 zh 覆盖应中文回答"

    def test_english_query_route_reasoning_english(self, kb_chat_url, kb_payload):
        """英文提问时 route_reasoning 事件 content 应为英文（P1 i18n 验证）。"""
        events = _sse_post(kb_chat_url, kb_payload("What is the boot process of Hi3798MV310?", stream=True))
        reasoning = [e.get("content", "") for e in events if e.get("type") == "route_reasoning"]
        assert reasoning, "未收到 route_reasoning 事件"
        # 至少一条进行中文案为英文

               any(_is_english(r) for r in reasoning), \
               f"route_reasoning 应含英文文案: {reasoning}"
```
