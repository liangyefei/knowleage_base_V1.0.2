原始项目需求：
1.支持pdf、word、execl、markdown、txt、html等类型文档接入知识库。
2.支持c、c++、python、TypeScript、ArkTs、Java、JavaScript等代码文件接入知识库
3.支持ini、dtsi、xml、sh、makefile等配置文件接入知识库。
4.支持方案、案例、wiki、FAQ等复合型文件被知识库学习。
5.知识库正确处理原理图、框图、Pin脚定义、寄存器表格等硬件专有信息，支持其结构化提取与向量库索引，使AI能够准确理解硬件内容。 
6.支持文档中图片数据接入。
7.支持建立代码与文档手册、原理图等的双向映射关系，使AI能知道手册如何映射到代码，通过代码可以查询相应的文档。
8.自动完成去重、无效过滤等数据清洗工作。
9.项目所使用第三方和开源软件、模型满足海思商用要求，具有可获得性，选型和海思对齐，模型优先选择国产模型。
10.所有原始文件的切片可以通过后台管理显性查看其正确性。
11.支持通过爬取网页、网站信息。
